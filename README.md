# Student Academic Performance Prediction

Predicting student academic performance based on study habits, engagement, and demographic factors.

## Dataset
- **Source:** UCI Student Performance Dataset
- **Link:** https://archive.ics.uci.edu/dataset/320/student+performance
- **Files:** 
  - `student-mat.csv` (Math course, 395 students)
  - `student-por.csv` (Portuguese course, 649 students)
- **Total Records:** 1,044 students
- **Features:** 33 attributes including demographics, study habits, social factors, and grades

## Project Goal
Build a Streamlit web app that:
1. Predicts final grade (G3) based on student characteristics
2. Identifies at-risk students early (without mid-term grades G1/G2)
3. Visualizes relationships between study behaviors and academic outcomes
